These public apps were copied from Greg Conradi Smith’s repositories on 2026-10-24. Original repositories and their history are preserved; archival eligibility is tracked separately. See `provenance.json` for exact source commits. Original README files, MATLAB references, scientific citations, and verification scripts are retained. No source repository supplied a license file at these commits; this integration does not relicense them under the website theme’s MIT license or grant additional rights.

Integration changes: academic-site return links and local provenance links, a relative Morris–Lecar cross-link, and directory-scoped service workers with separate academic cache namespaces. Trailing whitespace in the MATLAB reference copies was normalized. Models, scoring, assets, and app styles are otherwise retained. Optional GoatCounter analytics are retained in the four source apps that used them; simulations require no external libraries or assets.

Update from a public source commit only, review the upstream diff, preserve credits and any subsequently added license, reapply integration changes, then run numerical checks and browser checks at the nested URL. Do not replace the original repositories or redirect their published URLs without a separate request.
