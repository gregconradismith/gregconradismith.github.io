# Simulation provenance

Six public apps were copied from Greg Conradi Smith’s repositories on 2026-10-24. The FitzHugh–Nagumo network simulator was developed locally for classroom use and first published in this academic website repository on 2026-11-05. Its original standalone document and verification scripts are retained in the source commit identified in `provenance.json`; its integration adds only the academic-site navigation. Original repositories and their history are preserved; archival eligibility is tracked separately. See `provenance.json` for exact source commits. Original README files, MATLAB references, scientific citations, and verification scripts are retained. The six imported source repositories supplied no license file at their source commits, and no separate simulator license is declared for the FitzHugh–Nagumo app. This integration does not relicense these apps under the website theme’s MIT license or grant additional rights.

Integration changes: academic-site return links and local provenance links, a relative Morris–Lecar cross-link, and directory-scoped service workers with separate academic cache namespaces. Trailing whitespace in the MATLAB reference copies was normalized. Models, scoring, assets, and app styles are otherwise retained. Optional GoatCounter analytics are retained in the four source apps that used them; simulations require no external libraries or assets.

Update from a public source commit only, review the upstream diff, preserve credits and any subsequently added license, reapply integration changes, then run numerical checks and browser checks at the nested URL. Do not replace the original repositories or redirect their published URLs without a separate request.

2026-11-05: *From neurons to brain waves* is a new teaching simulator authored in this website repository. Its complete standalone source folder, academic-site navigation, documentation, and numerical/interaction checks are retained in the initial public source commit recorded in `provenance.json`. The following integration adds the catalogue entry and source record. It assigns rhythmic current dipoles to phase oscillators to illustrate coordination and cancellation; it is not a calibrated scalp-EEG model. No separate simulator license is declared, and no additional rights are granted by the website theme license.

Later on 2026-11-05, Greg requested a simpler brain-waves app with one population and equal additive contributions. The revised source uses one smooth current waveform, ordinary phase-attracting coupling, and the population average of all neuronal currents with identical positive weights. Group assignments, orientation controls, alternate waveforms, and the alternating preset were removed. `provenance.json` now points to the revised immutable public source commit and retains the preceding source commit for history.

The subsequent 2026-11-05 PSD display revision names the panel Power spectral density and adds a fixed logarithmic view (10⁻⁶–2 a.u.²/Hz, selected by default) alongside the existing fixed linear range (0–2). The plotting floor affects coordinates only; the calculated PSD, model, and retained signal are unchanged. The source record identifies the complete reviewed revision and retains the preceding source commit.

The next 2026-11-05 revision adds a head-to-tail phase-vector chain on the wheel, with one segment of length 1/N of the wheel radius per neuron. The chain starts at the center and ends at the existing mean alignment arrow. The frequency-spread range is extended to ±100%, reaching zero to twice the selected mean; defaults are retained. Numerical and interaction checks cover the complete chain and expanded range. The exact revised public source commit and preceding source are recorded in `provenance.json`.
